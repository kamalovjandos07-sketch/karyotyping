# Виртуальная лаборатория по кариотипированию

Интерактивный учебный веб-сайт для студентов медицинского университета. Симулирует полный процесс цитогенетического анализа с визуализацией лабораторного стола, реактивов и оборудования.

## Возможности

- Пошаговая симуляция 10 лабораторных этапов.
- Перетаскивание реактивов (drag & drop) на пробирку, предметное стекло и зону окрашивания.
- Взаимодействие с инкубатором и микроскопом.
- Визуализация метафазной пластинки и итогового кариотипа.
- Случайная генерация одного из 4 вариантов кариотипа:
  - Норма (46,XX или 46,XY)
  - Трисомия 21 (синдром Дауна)
  - Трисомия 18 (синдром Эдвардса)
  - Трисомия 13 (синдром Патау)

## Структура

- `index.html` — главная страница.
- `theory.html` — теоретический материал.
- `simulation.html` — интерактивная лабораторная симуляция.
- `styles.css` — стили.
- `simulation.js` — логика симуляции.
- `assets/` — изображения лаборатории, реактивов, оборудования и кариотипов.

## Как запустить

1. Клонируйте репозиторий или скачайте файлы.
2. Убедитесь, что все картинки из папки `assets/` присутствуют и названы так же, как в коде.
3. Откройте файл `index.html` в браузере (двойной клик или через `Open With...` → браузер).
4. Перейдите на вкладку «Симуляция», чтобы начать практику.

При необходимости можно разместить сайт на GitHub Pages: достаточно запушить репозиторий и включить GitHub Pages для ветки `main`.
