# Виртуальная лаборатория по кариотипированию

Статический учебный веб‑сайт для студентов медицинского университета, имитирующий
процесс цитогенетического анализа (кариотипирование).

## Структура

- `index.html` — главная страница
- `theory.html` — теоретический раздел
- `simulation.html` — интерактивная симуляция лаборатории
- `styles.css` — стили
- `main.js` — общая логика (навигация, статистика)
- `simulation.js` — логика симуляции, случайная генерация кариотипа

## Запуск

1. Склонируйте репозиторий или скопируйте файлы в папку проекта.
2. Откройте `index.html` двойным кликом или через локальный http‑сервер.
3. Для симуляции перейдите на страницу `simulation.html`.

## Функциональность

- Пошаговая симуляция 10 лабораторных этапов с проверкой правильной последовательности.
- Интерактивное перетаскивание реагентов и использование оборудования.
- Случайная генерация одного из 4 вариантов кариотипа:
  - Норма (46,XX или 46,XY)
  - Трисомия 21 (синдром Дауна)
  - Трисомия 18 (синдром Эдвардса)
  - Трисомия 13 (синдром Патау)
- Упрощённый «пазл» для сборки кариотипа и проверка диагноза.
- Локальная статистика (количество симуляций и правильных диагнозов).
